# 测试脚本梳理与清理

> 日期：2026-10-17
> 范围：当前仓库测试、测试夹具、开发验证入口与 CI 门禁。

## 范围与判断依据

清理前共有 331 个 `test*.py` 文件、3,176 个测试函数，pytest 参数展开后收集 6,032 项。
对全部测试模块提取了导入、测试名、断言、异常检查与参数化信息，扫描重复函数、同名覆盖、
无直接断言、跳过条件、源码扫描、真实时间依赖，并对清理候选及其替代覆盖逐项核对。
这不是对 12 万行测试代码的逐行人工审查，也不以用例数量或覆盖率单独判断价值。

没有发现完全相同的测试函数、同一作用域中被同名定义覆盖的测试或恒定布尔断言。
少数没有直接 `assert` 的测试通过子进程退出状态、事件完成或辅助断言验证行为，保留。
相似代码往往分别保护存储后端、协议编码、执行／恢复、进程内／worker 等不同边界，不能按相似度删除。

保留标准是能够拦截具体的功能、契约、安全、数据完整性、资源释放或成本回归。
已有真实行为覆盖的内部结构检查、重复的构造器约束，以及只冻结艺术效果的断言可以删除。
有价值但依赖短计时窗口的测试应先改为受控时钟或事件同步；平台前提不足不等于测试无效。

## 保留并修正的测试

过期预期同时对照现行契约核实：[子任务输入来源](../../specs/subagents.md)、
[Driver 结果投影](../../specs/runtime.md)、[推理偏好与摘要默认值](../../specs/provider-configuration.md)。
不以当前实现的输出本身作为修改测试预期的唯一依据。

- `test_adapter_stream.py`：使用只作用于 adapter 的时钟和事件交接，验证后续片段共享固定截止时间、
  等待预算递减、过期片段不额外等待；去掉 10 ms 睡眠和 25 ms 完成断言。
  真正的 asyncio 调度器保持不变，5 秒超时只用于发现挂起；流通过 `aclosing` 在失败时也释放。
- `test_plugin_examples.py`：回归发现 Configuration Playground 仍声明仅支持 OURO `<0.3.0`，
  在当前 0.3.0 中确实无法安装。保留这个有价值的测试，将示例兼容范围对齐其他当前示例的
  `>=0.3.0,<0.4.0`，并让验证失败直接展示诊断。测试中的配置默认值、凭据和 Schema 校验全部保留。
- `test_agents.py`：旧 Provider 替身仍按裸任务文字识别 child，现行模型输入已有 `subagent-task` 包络，
  导致预期的中断根本没有发生。按现行包络识别请求，并在恢复前断言 child 确实失败且只执行一次；
  上下文隔离测试同时验证 canonical 原文／标签和模型投影，保留父级秘密隔离与 token 预算断言。
- `test_tool_result_content.py`：删除必须把内部 Driver 路由写进模型正文的过期断言，
  验证现行 `driver-tool-result` 标签、调用身份及 canonical producer 中的 Driver 路由。
  三种协议、媒体保留／降级、无伪造模型调用的 6 个组合全部保留。
- `test_skill_loader.py`：删除旧版提示词措辞及历史命令措辞的断言；保留跨客户端发现、
  手动技能排除、名称和描述，改为验证两份实际 `SKILL.md` 路径，避免把文案微调视为功能故障。
- `test_attachments.py`：删除旧的二进制文件提示词断言，验证实际降级提示、文件名、内容未泄露及
  原始字节仍完整可取；图片输入、能力变化和上下文快照验证全部保留。
- `test_codex_subscription.py`：订阅集成使用已配置默认端点，避免绑定旧型号；请求断言覆盖当前
  `effort=medium, summary=auto` 设置。将 payload 断言移到 HTTP 替身外，避免被生产错误转换吞成
  模糊的“Model response could not be processed”。真实本地回调、持久化、重启、刷新、两轮工具、
  登出和脱敏验证仍在两种后端执行。
- `test_session_titles.py`：移除对已删除 `attachment_session()` 的调用，改用资源预留与
  `attachment_target()`；保留上传、引用、移除附件和附件先于文字的标题用例，额外确认准备附件
  不创建会话、提交沿用预留身份，避免恢复旧 API 来迎合测试。
- `test_background_navigation.py`：原“失败不覆盖另一会话”用例从欢迎页重新进入同一个欢迎页，
  却要求丢弃失败提交的原稿。现在真正切换到另一会话并预置不同草稿，验证目标草稿不变、原稿仍可恢复；
  不通过删除原稿来满足过期预期。
- `test_driver_agents.py`：全量并行覆盖率运行中，重启前等待子任务结算触发一次 10 秒超时，单独复现通过。
  失败现场两个子任务均已完成，最后完成事件距放行约 9.7 秒，已逼近限时；相邻组合正常完成。
  此处验证持久化恢复而非吞吐量，将这一步的挂起保护放宽为 30 秒，并增加两个子任务均成功完成的断言。
  保留进程内／worker、文件／SQLite、重启／不重启、审批／无操作的全部 16 个组合。
- `test_data_transfer.py`：全量运行暴露菜单辅助函数在后台目录扫描结束前点击文件的竞争，
  报 `OptionDoesNotExist`，单独运行通过。文件选择器准备期间旧菜单仍可见；改为等待目标选项
  实际出现在当前活动界面的列表中，再执行选择，不把一次 `pilot.pause()` 误当成后台读取完成。
  保留导航响应与旧读取结果不能覆盖新选择的断言。

未新增 `skip`、`xfail`、自动失败重试或覆盖率豁免，80% 覆盖率门槛保持不变。
升级夹具虽然包含旧格式，仍是当前升级功能的输入，不能作为“过期测试”删除。
POSIX 权限、Windows 控制台及符号链接等测试按实际平台前提执行，不能靠删除消除跳过数。
