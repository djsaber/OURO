## 执行规则

先核对现行契约、真实约束与责任层，再推进可独立验证的里程碑。每项计划说明正常、失败、取消、并发和恢复的验收证据；缺少外部前提时保留明确的未验证状态。

阶段执行受影响测试，整合与交付遵循[贡献指南](../../CONTRIBUTING.md)的完整门禁。不得把定向回归描述为全量通过，或以离线夹具替代真实账户、终端与平台验证。

已完成的计划移入[完成记录](archive/README.md)；当前设计仍由现行规格维护，避免在计划中另建一套有效契约。
