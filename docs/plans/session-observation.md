# 会话协作验收计划

> 文档类型：未完成工作规划
> 范围：跨平台重复终端验收、严格响应性指标和长时资源界限

本计划只跟踪多后台会话、会话切换及多终端观察的剩余验收。功能实施与阶段证据见
[阶段记录](archive/2026-10-23-session-observation.md)；历史 headless 测量和人工反馈不能代替本计划的退出条件。

## 现行契约与验收依据

- 执行归属、并发和 shutdown：[运行时规格](../specs/runtime.md)。
- 一致快照、独立游标、持久追赶和观察关闭：[会话观察规格](../specs/session-observation.md)。
- Agent 状态通知和控制：[子智能体规格](../specs/subagents.md)。
- 视图生命周期、近期窗口、草稿与滚动：[TUI 规格](../specs/tui.md)。
- 热路径和成本边界：[性能规格](../specs/performance.md)。

响应性目标、每场景重复次数和超预算后的优化门槛统一由[性能规划](performance.md)定义。
本计划负责组合场景和验收证据，不另设指标或维护第二套运行契约。

## 跨平台终端验收

使用临时 home 和合成 Provider，Files 与 SQLite 分别运行。在 Windows Terminal/PowerShell 和受支持的
POSIX 终端重复以下场景；同进程集成、真实进程 headless 与实际终端分别记录，不互相替代。
人工入口和计量口径见[本地基准说明](../../dev/benchmarks/README.md#人工终端验收入口)。

- [ ] TUI A 同时运行三个 Session，快速 A→B→C 切换；验证正文、草稿、焦点、队列和滚动位置的归属。
- [ ] TUI B 在另一进程观察同一 Session；暂停消费使积压超过实时缓存，恢复后按持久游标完整追赶。
- [ ] 在持续流、工具批次、审批和 AskUser 中输入与切换，验证操作目标和等待状态准确。
- [ ] 连续多个 Run 的正式正文、工具结果与终态摘要完整，无重复、缺口或旧视图覆盖。
- [ ] 关闭观察者后运行继续；分别执行显式 abort、正常完成和应用 shutdown，验证各自生命周期结果。
- [ ] 验证读取失败后的诊断、明确重试与资源释放；history_epoch 改变或旧任务晚到不混合历史代次。

## 响应性与资源界限

- [ ] 在短历史、1,000/10,000 条消息下重复测量冷进入、缓存重进、流式重进和向上补页。
- [ ] 覆盖普通增量、突发增量、多后台会话和双观察者；记录首个可用画面、按键尾延迟、loop lag 与实际 paint。
- [ ] 分别计量读取量、查询次数、排版项、在途任务、订阅、线程、进程和缓存；后台不可见会话不持续绘制正文。
- [ ] 长时运行并反复切换、断开和重连，验证任务、订阅与缓存不持续增长，最后一个观察者关闭后释放观察资源。
- [ ] 对超预算场景定位业务边界，再决定优化或暂缓；保存完整样本、尾部和判断依据，不用单次结果或平均值替代验收。

## 验证与收尾

并发回归用 Event、队列和进程握手建立边界；timeout 只作挂起保护。自动化检查行为、内容和资源成本，
终端外观与键盘链路按[测试策略](../development/testing.md)人工验收。仅因发现实现缺陷而修改代码时，
执行对应受影响边界回归，并记录范围；整合门禁遵循[贡献指南](../../CONTRIBUTING.md)。

- [ ] 记录平台、终端、后端、依赖版本、负载、样本数和不可观测项，明确失败或未验证范围。
- [ ] 严格响应性指标及组合场景均达到退出条件；未达到的场景继续保留在本计划。
- [ ] 如验收发现契约与实现不一致，同步修正权威规格和对应回归，不把修正只留在计划中。
- [ ] 完成后归档验收证据并更新规划索引，现行设计文档只保留有效契约。
