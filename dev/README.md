# 开发工具

本目录保存开发和验证工具；产品说明、领域规格和规划统一从[文档中心](../docs/README.md)进入。

| 目录 | 用途 | 使用前提 |
|---|---|---|
| [benchmarks](benchmarks/README.md) | 本地性能测量、存储同步和响应性采样 | 使用临时数据，记录平台、规模和样本数 |
| [probes](probes/README.md) | 显式授权的订阅协议与真实服务验证 | 人工参与授权，避免保存或输出秘密 |

基准结果不等于真实终端或外部服务的性能保证。联网探针与普通离线测试分开运行；开发门禁见[贡献指南](../CONTRIBUTING.md)。
