# 模型订阅认证实施计划

> 文档类型：未来规划
> 规划基线：2026-09-16
> 状态：浏览器订阅产品、驱动、模板、服务策略及 Application/CLI/TUI 已内建接线；正式 adapter 真实文本/工具/刷新续接已通过；持久凭据和文件/SQLite Runtime 闭环已通过合成 HTTP 集成验收；真实账户持久登录、check/run、跨进程续接及注销已通过 Windows/browser/gpt-5.5 验收；设备码、其余模型能力与平台验证仍待完成。

目标是交付多厂商认证边界与首个 OpenAI 订阅组合。设计取舍见[目标设计](../../docs/OURO_模型订阅认证扩展设计_2026-09-16.md)，权威契约及验收编号见[模型订阅认证规格](../specs/OURO_模型订阅认证规格_2026-09-16.md)。本计划只安排实施工作，不重复维护状态机、schema 或安全规则。

## 前置与实施原则

- 阅读现行开发架构、编码准则及 Provider 配置/类型/模板规格；以代码校准差异。
- 保持静态 API Key 行为，使用现有配置 mutation、HTTP/SSE、retry、Session 和账本能力。
- 每阶段形成可独立验证的提交；领域/协议变化先于 Host 接线，不顺手重构无关模块。
- 不添加多层重复校验、额外授权审批、动态插件框架、历史迁移或第二套运行状态。
- 首期生产存储只交付受限文件 store，系统钥匙串不作为完成条件。
