# 模型订阅认证验证与扩展计划

## 当前边界

OURO 使用 AuthDriver、CredentialService 和 RequestAuthenticator 组合认证；OpenAI 浏览器订阅通过 Responses adapter 进入统一 Runtime、CLI 和 TUI。设计见[订阅认证设计](../../docs/OURO_模型订阅认证扩展设计_2026-09-16.md)，契约见[订阅认证规格](../specs/OURO_模型订阅认证规格_2026-09-16.md)，支持和验证范围见[使用指南](../../docs/OURO_订阅支持使用指南_ZH_2026-09-19.md#证据范围)。

本计划只列待验证能力和扩展条件。实现事实由现行规格负责，不维护已完成实施记录。

## 待验证能力

- [ ] 通过显式启用的隔离探针验证设备码授权、刷新和模型调用；取得证据后再注册生产驱动方法。
- [ ] 核验各模型的 reasoning 等级、上下文窗口、参数限制、账户/区域及错误行为；图像与结构化输出分别验收。
- [ ] 在 POSIX 平台验证凭据目录、临时文件、替换原语和权限保护。
- [ ] 覆盖无图形界面、端口冲突、长会话、进程重启及跨平台关闭行为。
- [ ] 按[验收矩阵](../specs/OURO_模型订阅认证规格_2026-09-16.md#s10-验收矩阵)补齐真实账户证据；fixture 只保存脱敏协议事实。

## 实施规则

复用配置事务、请求重试、Session、工具循环和用量账本。新厂商首先增加驱动及产品/服务数据，只有线协议不同才增加 adapter；Host 和 Core 不包含品牌判断。

设备码方法复用统一 challenge、取消和凭据提交边界。网络等待不持配置锁；credential 锁先于配置锁；取消后等待已开始的持久化操作收尾。失败不自动切换账户、模型或计费来源。

不得读取其他客户端凭据，不以真实秘密构造测试夹具，不以单轮文本成功代替登录、刷新、工具续接、恢复和注销验收。外部前提不足时明确支持边界。

## 验收

执行对应契约、失败/并发/取消测试和[完整工程门禁](../../CONTRIBUTING.md)。真实账户和平台验证独立执行，不将离线测试解释为外部服务保证。维护现行规范和使用指南中的有效行为、参数及限制，不追加长期实施日志。
