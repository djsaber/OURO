# OURO 用量与计费规格

> 文档类型：现行规格
> 代码基线：2026-09-17
> 主要实现：`core/billing.py`、`application/usage.py`、`billing/local.py`、CLI/TUI 用量呈现

## 数据与责任边界

`Usage` 只承载供应商返回的实际 token 与可确认的 USD 金额；上下文估算不进入账本。input 包含 cached input，缓存读写仅提供其中的细分，不重复加入 total；reasoning token 不重复计入 output。普通回合和压缩请求在供应商完成响应时通过同一 UsageService 记录，即使之后的摘要校验失败也保留已经发生的用量。

计费模式是服务连接的声明，不是登录方式、账户身份或模型名称的推论。`BillingMode` 仅含 `unknown`、`usage_based`、`subscription`；没有明确服务声明时为 unknown，不能依据 static/OAuth 或有无 API Key 推断计费方式。

组合根注入的 `ProviderRequestPolicy.billing_mode` 由 adapter factory 固定到 `ModelMetadata.billing_mode`。模型请求与压缩请求把当次 adapter 的模型快照交给记账用例；UsageService 不查询当前 Provider 配置。进行中的请求不会因实例绑定变化改写归属，下一请求使用重新解析的 adapter。自行构造 RuntimeAdapter 的调用方同样负责提供其服务声明；没有声明保持 unknown。

这项归属不增加认证字段、账户标识、供应商秘密或另一套运行状态；`Usage`、Run token 累加与预算判断保持数值契约。

## 请求账本

每条 `ProviderUsageEntry` 的 `metadata.billing_mode` 保存请求时的计费模式，`billing_mode` 属性提供类型化读取；metadata 中的非法值在模型校验时拒绝，未声明值为 unknown。新写入的记录总是包含该字段。

账本继续使用全局 `billing/usage.jsonl`、追加事件、独立写锁和请求身份幂等性，不增加文件格式、认证状态或附属计数。相同请求重复记账必须保持计费模式一致；即使金额已经人工修订，重新提交也不能改变来源。人工修改 token/金额保留原始计费模式，reset 保留审计历史。

订阅不等于零金额，也不意味着可以估算单次费用。没有可确认单次金额时 `estimated_cost=None`；实际已知的 `0.0` 是 priced 请求。框架不摊分订阅月费，不推算远端额度，不以订阅身份填入普通 API 定价。

## 汇总与 Host

`UsageTotals` 复用 request_count、estimated_cost、priced_request_count 和 unpriced_request_count；estimated_cost 是已知金额的合计，不能单独表示所有请求的完整花费。`billing_modes` 是参与本次汇总的模式去重排序结果，空记录为 `()`，不持久化第二份汇总。

- `usage summary --group-by billing_mode` 复用已有分组能力；按日期或其他维度查询同样只使用账本事实。
- CLI summary 展示未知金额请求数、涉及的计费模式以及未知/部分金额；list 输出请求原始 billing_mode，show/JSON 保留 metadata。
- TUI 主页 USAGE 总览和日期悬停仅展示请求数、输入/输出 token 和缓存命中率，不展示费用或计费信息；框架与 CLI 保留完整账本查询能力。
- token、轮次预算继续有效；未知金额不能保证严格 USD 预算。没有额度查询后台任务或订阅费用分摊系统。

## 验收证据与范围

- `tests/application/test_billing_attribution.py`：请求中切换绑定、下一请求重新归属、实际 Runtime 与专用压缩记账、未知金额、重开账本、幂等冲突和人工修订。
- `tests/application/test_usage.py`、`tests/billing/`：现有过滤、汇总、追加审计与账本锁边界。
- `tests/providers/test_factory.py`：协议与认证类型不决定计费模式，显式服务声明进入模型快照。
- `tests/cli/test_usage_commands.py`：未知、零金额、混合金额及来源分组。
- `tests/tui/test_usage_presentation.py`：不同计费状态下仅展示用量，验证日期悬停及不同终端宽度。

这些证据使用测试服务声明，不代表生产订阅服务已注册或已验证真实权益。生产接入仍遵循[模型订阅认证实施计划](../plans/OURO_模型订阅认证实施计划_2026-09-16.md)。
